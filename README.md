# Queens Medicare

Queens Medicare is a website for a maternity and women's care hospital in Lucknow. It introduces the hospital, its care services, and ways for patients and families to get in touch.

## Website sections

- **Home** — an overview of Queens Medicare and its care.
- **Care & Services** — information about maternity and women's health services.
- **About Us** — the hospital's story and team.
- **Visit Us** — contact details and location information.

## Technology

- React and TypeScript
- TanStack Start and TanStack Router
- Tailwind CSS
- Vite

## Run locally

Requires Node.js 22.12 or newer and npm 10 or newer.

```sh
npm ci
npm run dev
```

The development server runs at [http://localhost:5175](http://localhost:5175).
